Contributing
============

Start with the `contribution guide <https://github.com/EJainDev/AnnoTest/blob/improved-features/CONTRIBUTING.md>`_
for repository conventions. Use the `issue tracker <https://github.com/EJainDev/AnnoTest/issues>`_
to report reproducible defects or propose changes.

A contribution that changes public behavior should include a regression test
and an update to the relevant reference entry or guide. Tests for a testing
library should check both successful execution and the diagnostics, cleanup,
and control flow produced by failures.

See :doc:`/testing` for build, test, coverage, and consumer checks.
